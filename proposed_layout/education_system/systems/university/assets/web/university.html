SQLite Database

The University System uses SQLite (WAL mode). Database files live under each system's data/db_files/ directory on the server and are never served over HTTP. Query them locally with the CLI/GUI or a SQLite client on the machine that hosts the application.

Note: The web server exposes only this static UI. Raw database files (records, auth.db, audit.db) are intentionally not downloadable — they contain password hashes, MFA secrets and personal data.
