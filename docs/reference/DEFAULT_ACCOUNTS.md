# Default Accounts

Pre-seeded development credentials for the four subsystems. **Change every password before deploying to any non-development environment.** After 5 failed login attempts an account is locked for 15 minutes — sign in as the system admin and clear the lockout from the admin panel.

|----------|----------|------|
| `superadmin` | `SuperAdmin@123` | Admin across university, college, secondary, and primary |
