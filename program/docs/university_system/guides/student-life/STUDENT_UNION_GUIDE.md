## Getting Started

### Accessing the Student Union System

**From GUI:**
1. Launch main application
2. Navigate to **Student Affairs** → **Student Union**
3. Login with credentials

**User Roles:**
- **Students**: Join clubs, book facilities, participate in events
- **Club Officers**: Manage club activities, events, memberships
- **Union Officers**: Oversee all union activities, approve budgets
- **Admin**: System configuration, user management

### First-Time Setup

**For Students:**
1. Complete your profile (interests, skills, availability)
2. Browse and join clubs/societies
3. Subscribe to event notifications
4. Set communication preferences

**For Club Officers:**
1. Register your club/society
2. Add executive members
3. Set up club profile and description
4. Submit budget request

## Event Management

### Creating an Event

**Steps:**
1. Click **Create Event** from dashboard or Events tab
2. Fill in event details:
   - **Event Name**: Clear, descriptive title
   - **Category**: Social, Academic, Sports, Cultural, Charity, Other
   - **Date & Time**: Start and end times
   - **Location**: Building and room, or external venue
   - **Capacity**: Maximum attendees
   - **Registration Deadline**: Last day to sign up
3. Add event description:
   - Purpose and agenda
   - Target audience
   - What to bring (optional)
4. Configure settings:
   - **Requires Registration**: Pre-registration required
   - **Public Event**: Open to all students vs. club members only
   - **Ticketed**: Free or paid event
   - **Waitlist**: Enable if full
5. Upload event image (optional, 16:9 ratio recommended)
6. Submit for approval (if required)

### Event Registration

**For Students:**
1. Browse **Events** tab
2. Use filters:
   - Date range
   - Category
   - Club/organization
   - Free vs. paid
3. Click event to view details
4. Click **Register**
5. Complete any required forms
6. Make payment (if ticketed)
7. Receive confirmation email with calendar invite

**Waitlist:**
- If event is full, join waitlist
- Automatic notification if spot becomes available
- 24-hour window to confirm registration

### Managing Events (Organizers)

**Before Event:**
- Monitor registration numbers
- Send reminder emails (auto-sent 24 hours before)
- Update event details if needed
- Generate attendee list

**During Event:**
- Check-in attendees (QR code or manual)
- Record actual attendance
- Live updates (photos, posts)

**After Event:**
- Mark as completed
- Collect feedback (auto-survey sent)
- Review analytics
- Submit expense report

**Event Analytics:**
- Registration conversion rate
- Actual vs. expected attendance
- Demographics (year, major, college)
- Feedback scores and comments
- Photo gallery

## Facility Booking

### Available Facilities

**Student Union Building:**
- Meeting rooms (capacity 5-20)
- Auditorium (capacity 200)
- Games room
- Study spaces
- Kitchen/catering area
- Common lounge

**External Facilities:**
- Sports hall
- Outdoor spaces (courtyards, fields)
- Conference center

### Booking a Facility

**Steps:**
1. Navigate to **Facilities** → **Book Space**
2. Select facility type and capacity needed
3. Choose date and time slot
4. View availability calendar (green = available, red = booked)
5. Click time slot to book
6. Fill booking form:
   - **Purpose**: Event, meeting, study group, etc.
   - **Club/Organization**: If applicable
   - **Setup Requirements**: Tables, chairs, AV equipment
   - **Catering**: Food/beverage needs
   - **Expected Attendees**: Number of people
7. Review booking policy and terms
8. Submit booking request

**Booking Rules:**
- Maximum 2 weeks in advance for general bookings
- Club events: Up to 6 weeks in advance
- Large events (50+ people): 4 weeks notice required
- Cancellation: 48 hours notice to avoid fee

**Booking Approval:**
- Automatic approval for small rooms (<10 people)
- Manual approval for auditorium, large events
- Notification sent within 24 hours

### Managing Bookings

**View Your Bookings:**
1. Navigate to **My Bookings** tab
2. See list of upcoming and past bookings
3. Actions:
   - **Modify**: Change time, attendees, setup (subject to approval)
   - **Cancel**: Cancel booking (refund if applicable)
   - **Extend**: Request additional time
   - **Repeat**: Create recurring booking

**Room Setup Requests:**
- Standard setups: Theater, classroom, U-shape, boardroom
- Custom setup: Specify layout in notes
- AV equipment: Projector, microphone, speakers
- Submit at least 3 days before event

## Elections

### Election Types

1. **Union Officer Elections**: President, VP, Treasurer, etc.
2. **Club Executive Elections**: Club-specific leadership
3. **Student Representative Elections**: Faculty/department reps
4. **Referenda**: Policy decisions, constitutional changes

### Setting Up an Election (Admin)

**Steps:**
1. Navigate to **Elections** → **Create Election**
2. Basic information:
   - **Election Name**: e.g., "2026 Union Officer Elections"
   - **Type**: Officer, Representative, Referendum
   - **Start Date**: Nomination opening
   - **Nomination Deadline**: Last day to submit nomination
   - **Campaign Period**: Start and end dates
   - **Voting Period**: Voting open and close times
3. Configure positions:
   - Add positions (President, VP Finance, etc.)
   - Set eligibility criteria (year, GPA, club membership)
   - Number of winners per position
4. Voting method:
   - **First Past the Post**: Simple majority
   - **Single Transferable Vote (STV)**: Ranked choice
   - **Approval Voting**: Approve multiple candidates
5. Campaign rules:
   - Spending limits
   - Permitted materials
   - Debate schedule
6. Accessibility settings:
   - Screen reader support
   - Alternative text for images
   - Extended voting time option
   - Assistance available
7. Publish election

### Running for Office (Candidates)

**Nomination Process:**
1. Navigate to active election
2. Click **Nominate Yourself** for a position
3. Fill nomination form:
   - Personal statement (500 words)
   - Manifesto (1000 words)
   - Profile photo
   - Contact information
4. Upload supporting documents:
   - Nomination signatures (if required)
   - Eligibility proof (transcript, membership card)
5. Submit nomination
6. Await approval from election committee

**Campaign Tools:**
- Create campaign page with photos, videos, policies
- Post updates and announcements
- Schedule campaign events
- Track supporter count
- Spending tracker (ensure within limits)
- Social media integration

**Campaign Accessibility:**
- Auto-generate plain text version of manifesto
- Alt text for all images required
- Captioned videos
- Large print/high contrast options

### Voting (Students)

**How to Vote:**
1. Navigate to **Elections** during voting period
2. View list of active elections/positions
3. Click **Cast Vote** for a position
4. Review candidates:
   - Read manifestos
   - Watch video statements
   - Compare policies
5. Make selection:
   - **FPTP**: Choose one candidate
   - **STV**: Rank candidates in preference order
   - **Approval**: Select all acceptable candidates
6. Review your vote
7. Submit (anonymous and secure)
8. Receive confirmation

**Voting Features:**
- Anonymous voting (unlinkable to identity)
- One vote per position per student
- Change vote before deadline
- Accessibility: Screen reader compatible, keyboard navigation
- Multiple voting methods: Web, mobile app, in-person

**Election Results:**
- Published automatically after close
- Live results display (if enabled)
- Breakdown by position
- Turnout statistics
- Re-run ballot if tie/no majority

## Club & Society Management

### Registering a New Club

**Requirements:**
- Minimum 10 founding members
- Faculty advisor
- Constitution/bylaws
- Budget plan

**Steps:**
1. Navigate to **Clubs** → **Register New Club**
2. Fill registration form:
   - Club name and acronym
   - Category (Academic, Sports, Cultural, Social, Service)
   - Description and mission
   - Founding members (names and student IDs)
   - Faculty advisor details
3. Upload documents:
   - Draft constitution
   - Proposed budget
   - Activity plan for year
4. Submit for review
5. Await approval (typically 2 weeks)

**After Approval:**
- Receive club ID and email address
- Access to club management dashboard
- Allocated budget (if applicable)
- Can start recruiting members

### Managing Club Membership

**Adding Members:**
- **Open Enrollment**: Students join directly
- **Application-Based**: Officers review and approve
- **Invitation-Only**: Officers invite specific students

**Member Management:**
1. Navigate to **Members** tab
2. View member list with roles
3. Actions:
   - **Add Member**: Invite by email or student ID
   - **Promote**: Assign roles (President, Secretary, Treasurer, etc.)
   - **Remove**: Remove inactive/graduated members
   - **Export**: Download member list (CSV)

**Member Roles:**
- **President**: Overall leadership
- **Vice President**: Deputy leader
- **Treasurer**: Financial management
- **Secretary**: Communications and records
- **Event Coordinator**: Organize activities
- **General Member**: Voting member

**Membership Types:**
- **Full Member**: All privileges, voting rights
- **Associate Member**: Limited participation
- **Alumni Member**: Graduated members (non-voting)

### Club Communications

**Announcement System:**
1. Navigate to **Communications**
2. Create announcement
3. Select audience: All members, Officers only, Specific years
4. Choose channels: Email, SMS, In-app notification
5. Schedule or send immediately

**Mailing Lists:**
- Automatic club mailing list created
- Format: clubname@union.university.edu
- Officers can send to all members

**Social Media Integration:**
- Link club social accounts
- Cross-post announcements
- Sync event promotion

## Payment Processing

### Setting Up Payments

**For Event Tickets:**
1. When creating event, enable **Ticketed**
2. Set ticket prices:
   - **General Admission**: Default price
   - **Member Discount**: Reduced price for club members
   - **Early Bird**: Discount for early registration
3. Choose payment methods:
   - Credit/Debit card
   - Student account balance
   - Cash (in-person payment)
4. Payment deadline: Registration close or 24 hours before
5. Refund policy: Full refund up to 48 hours before

**For Membership Dues:**
1. Navigate to **Club Settings** → **Membership Fees**
2. Set annual fee amount
3. Configure payment terms:
   - Due date (e.g., start of term)
   - Payment plans (one-time, termly, monthly)
   - Grace period before suspension
4. Enable auto-renewal (optional)

### Processing Payments (Officers)

**View Transactions:**
1. Navigate to **Payments** → **Transaction History**
2. View table with:
   - Date, student name, amount, purpose
   - Payment method, status
   - Receipt number
3. Filter by date range, status, event

**Manual Payment Entry:**
- For cash payments received in person
- Click **Record Payment**
- Enter student ID, amount, purpose
- Upload proof (photo of cash/check)
- Generate receipt

**Refunds:**
1. Find transaction in history
2. Click **Issue Refund**
3. Select reason: Cancellation, overpayment, error
4. Choose refund method: Original payment method or student account
5. Confirm refund
6. Student receives notification and refund within 5-7 business days

**Financial Reports:**
- **Revenue Report**: Income by source (events, dues, donations)
- **Expense Report**: Spending by category
- **Budget vs. Actual**: Variance analysis
- **Outstanding Payments**: Members with unpaid dues

## Peer Support

### Peer Mentorship Program

**For Mentors:**
1. Apply to become a peer mentor
2. Complete training modules (mental health first aid, active listening)
3. Pass background check
4. Get matched with mentees (1-3 students)
5. Schedule regular check-ins (weekly/bi-weekly)
6. Use mentorship dashboard to:
   - Log meeting notes
   - Track mentee progress
   - Access resources
   - Request supervisor support

**For Mentees:**
1. Request a peer mentor
2. Fill matching questionnaire (interests, needs, availability)
3. Get matched within 1 week
4. Initial meeting with mentor
5. Set goals collaboratively
6. Meet regularly and provide feedback

**Mentorship Features:**
- Matching algorithm based on compatibility
- Secure messaging between mentor and mentee
- Resource library (study skills, wellbeing, career)
- Group mentoring sessions
- Progress tracking and goal setting

### Peer Counseling

**Anonymous Support:**
- Text-based chat with trained peer counselors
- Available 7 days/week, 6 PM - 12 AM
- Completely anonymous and confidential
- Crisis escalation to professional services

**Support Groups:**
- Weekly peer-led support groups
- Topics: Stress management, homesickness, academic pressure, identity
- Safe, non-judgmental space
- Professional staff supervision

## Academic Support

### Study Groups

**Finding Study Groups:**
1. Navigate to **Academic Support** → **Study Groups**
2. Search by course code or subject
3. View available groups with:
   - Course, topic, meeting time
   - Current members, capacity
   - Leader and description
4. Click **Join Group**

**Creating Study Groups:**
1. Click **Create Study Group**
2. Fill details:
   - Course and topic
   - Meeting schedule (day, time, location)
   - Maximum members (5-10 recommended)
   - Study style (collaborative, quiz-based, lecture review)

4. Use group chat for coordination

**Booking a Tutor:**
1. Navigate to **Tutoring**
2. Select subject and topic
3. View available tutors (ratings, availability, hourly rate)
4. Choose tutor
5. Select time slot
6. Confirm booking

**Becoming a Tutor:**
- Requirements: GPA 3.5+ in subject, faculty recommendation
- Apply and submit transcript
- Complete tutor training
- Set availability and rate
- Receive bookings and payment through system

### Academic Workshops

**Attending Workshops:**
- Weekly workshops on study skills, time management, exam prep
- Register through Events system
- Free for all students
- Certificates of completion available

## Troubleshooting

### Common Issues

**"Cannot register for event"**
- Event may be full (check waitlist)
- Registration deadline may have passed
- Payment issue (check payment method)
- Eligibility restriction (club members only)

**"Booking request denied"**
- Conflict with another booking
- Insufficient notice period
- Facility unavailable (maintenance)
- Incomplete booking information

**"Vote not submitted"**
- Voting period may have ended
- Browser cookies disabled (enable cookies)
- Network connection issue
- Already voted (cannot vote twice)

**"Payment failed"**
- Insufficient funds
- Card declined
- Payment gateway timeout
- Invalid payment details

## Best Practices

### For Club Officers

1. **Communication**: Send regular updates to members
2. **Planning**: Create events at least 3 weeks in advance
3. **Budgeting**: Track expenses monthly, avoid overspending
4. **Inclusivity**: Make events accessible to all students
5. **Documentation**: Keep meeting minutes and records
6. **Transition**: Prepare handover documents for new officers

### For Students

1. **Get Involved**: Join at least one club
2. **Attend Events**: Participate in union activities
3. **Vote**: Participate in elections
4. **Provide Feedback**: Help improve services
5. **Volunteer**: Contribute to peer support programs
