# Accessibility Services - User Guide

## Overview

The Accessibility Services system manages accommodation requests, disability documentation, and support services for students with disabilities. It provides a streamlined process for requesting accommodations, uploading medical documentation, communicating with disability services staff, and notifying faculty of approved accommodations. The system is fully FERPA-compliant with encrypted document storage.

## Getting Started

### Accessing Accessibility Services

**For Students:**
1. Navigate to **Student Services** → **Accessibility Services**
2. Login with university credentials
3. Complete intake form (first-time users)

**For Faculty:**
1. Navigate to **Academics** → **Accessibility Notifications**
2. View accommodation letters for your students

**For Disability Services Staff:**
1. Navigate to **Administration** → **Accessibility Services**
2. Full access to all requests, documentation, and management tools

### First-Time Registration

**Student Intake Process:**
1. Navigate to **Accessibility Services** → **Register**
2. Complete intake form:
   - Personal information
   - Disability type and description
   - Accommodation history (if any)
   - Current courses and schedule
3. Upload supporting documentation
4. Schedule intake appointment with disability specialist
5. Submit registration

## Requesting Accommodations

### Submitting an Accommodation Request

**Create a Request:**
1. Navigate to **Accommodations** → **New Request**
2. Select accommodation type:
   - Extended Time
   - Note-Taking
   - Sign Language Interpretation
   - Accessible Seating
   - Adaptive Technology
   - Other (describe)
3. Provide details:
   - Courses requiring accommodation
   - Specific needs and preferences
   - Semester/term for the accommodation
4. Upload supporting documentation (medical records, evaluations)
5. Submit request

### Request Workflow

**Status Progression:**

```
Submitted → Under Review → Approved/Denied → Active
```

**Status Definitions:**
- **Submitted**: Request received, awaiting review
- **Under Review**: Disability specialist evaluating request and documentation
- **Approved**: Accommodation granted
- **Denied**: Accommodation not approved (with explanation)
- **Active**: Accommodation in effect for current semester
- **Expired**: Accommodation period ended (renewal available)

### Renewing Accommodations

**Accommodation Renewal:**
1. Navigate to **Accommodations** → **My Accommodations**
2. Select accommodation nearing expiration
3. Click **Request Renewal**
4. Update any changes to needs
5. Submit renewed documentation if required
6. Submit renewal request

## Accommodation Types

### Extended Time

**Description**: Additional time on exams and timed assignments.

**Details:**
- Typically 1.5x or 2x standard time
- Applies to all timed assessments
- Testing may be in a separate, distraction-reduced environment
- Arrangements made through Testing Center

### Note-Taking Services

**Description**: Professional or peer note-takers for lectures.

**Options:**
- Peer note-taker assigned from the class
- Digital note-taking tools provided
- Faculty lecture notes/slides provided in advance
- Audio recording permission granted

### Sign Language Interpretation

**Description**: ASL interpreter for classes, labs, and academic events.

**Arrangements:**
- Interpreter assigned to scheduled classes
- Advance notice required for special events
- Video relay services for virtual classes
- Priority seating near interpreter

### Accessible Seating

**Description**: Reserved accessible seating in classrooms and lecture halls.

**Options:**
- Front-row seating
- Wheelchair-accessible locations
- Seating near exits
- Adjustable furniture

### Adaptive Technology

**Description**: Assistive technology and software for academic work.

**Available Technologies:**
- Screen readers (JAWS, NVDA)
- Text-to-speech software
- Speech-to-text dictation
- Magnification software
- Alternative input devices
- Braille displays

### Other Accommodations

**Additional Options:**
- Reduced course load
- Housing accommodations
- Dietary accommodations
- Flexible attendance policies
- Alternative format materials (large print, Braille, audio)
- Emotional support animal approval
- Priority course registration

## Documentation

### Required Documentation

**Supporting Documents:**
- Medical records or physician's letter
- Psychological evaluation
- Educational assessment
- Prior accommodation records (IEP, 504 plan)
- Specialist reports (audiologist, ophthalmologist, etc.)

### Uploading Documents

**Submit Documentation:**
1. Navigate to **Documentation** → **Upload**
2. Select document type
3. Upload file (PDF, JPG, PNG, DOCX)
4. Enter description and date of document
5. Submit
6. Document encrypted and stored securely

### Document Requirements

**Documentation Must Include:**
- Qualified professional's diagnosis
- Description of functional limitations
- Recommended accommodations
- Date of evaluation (within 3 years preferred)
- Professional's credentials and contact information

**Document Security:**
- All documents encrypted at rest
- Access restricted to authorized disability services staff
- FERPA-compliant storage and handling
- Documents never shared with faculty (only accommodation letters)

## Faculty Notifications

### How Faculty Are Notified

**Accommodation Letters:**
- When an accommodation is approved, an accommodation letter is generated
- The letter is sent to all relevant course instructors
- Letters specify the accommodation type and requirements
- Letters do NOT include diagnosis or medical details

**Notification Contents:**
- Student name
- Approved accommodation(s)
- Implementation instructions
- Semester/term effective
- Contact information for questions

### Student Control

**What Students Control:**
- Choose which courses receive accommodation letters
- Request new letters for added courses
- Delay or pause accommodation notifications
- Revoke accommodation letters if desired

## For Faculty

### Receiving Accommodation Notifications

**When You Receive a Letter:**
1. Review the accommodation letter
2. Understand the required accommodation
3. Implement accommodations in your course:
   - Extended time: Coordinate with Testing Center
   - Note-taking: Assist in identifying a note-taker
   - Accessible materials: Provide materials in requested format
   - Seating: Reserve appropriate seating
4. Contact Disability Services with any questions

### Faculty Responsibilities

**Required Actions:**
- Implement approved accommodations promptly
- Maintain confidentiality of accommodation information
- Do not request medical details from the student
- Contact Disability Services (not the student) with concerns
- Ensure testing accommodations are arranged in advance
- Provide materials in accessible formats when requested

### Reporting Concerns

**If Issues Arise:**
1. Navigate to **Accessibility Notifications** → **Report Concern**
2. Describe the situation
3. Disability Services will mediate and assist
4. Never deny an approved accommodation

## Privacy & Compliance

### FERPA Compliance

**Privacy Protections:**
- Medical documentation is confidential
- Only authorized Disability Services staff access records
- Faculty receive accommodation letters only (no diagnoses)
- Students control which courses receive notifications
- All data encrypted at rest and in transit

### Student Rights

**Under ADA/Section 504:**
- Right to request reasonable accommodations
- Right to confidentiality of disability information
- Right to equal access to academic programs
- Right to appeal accommodation decisions
- Right to file grievance for denied accommodations

### Data Retention

- Active accommodation records: Maintained while enrolled
- Documentation: Retained per institutional policy
- Expired accommodations: Archived for 7 years
- Communication records: Retained for 3 years

## Best Practices

### For Students

1. **Register early** - Submit requests before the semester starts for timely processing
2. **Provide thorough documentation** - Complete documentation speeds up the review process
3. **Communicate proactively** - Inform instructors of your accommodations early in the semester
4. **Renew on time** - Start renewal process 4-6 weeks before expiration
5. **Report issues immediately** - Contact Disability Services if accommodations aren't being implemented

### For Faculty

1. **Implement promptly** - Begin accommodations as soon as you receive the letter
2. **Maintain confidentiality** - Never discuss a student's accommodations publicly
3. **Be proactive** - Include accessibility information in your syllabus
4. **Ask Disability Services** - Direct questions to the office, not the student
5. **Document implementation** - Keep records of accommodations provided

## Troubleshooting

### Common Issues

**Request taking too long:**
- Check if additional documentation was requested
- Verify all required fields were completed
- Contact Disability Services for status update
- Typical processing time: 5-10 business days

**Faculty not implementing accommodation:**
- Verify the accommodation letter was sent to the instructor
- Contact Disability Services to send a reminder
- Request a meeting to discuss implementation
- File a formal concern if accommodation is consistently denied

**Documentation rejected:**
- Review documentation requirements
- Ensure evaluation is within the acceptable date range
- Verify the evaluator's qualifications meet requirements
- Contact Disability Services for guidance on acceptable documentation

**Cannot upload documents:**
- Accepted formats: PDF, JPG, PNG, DOCX
- Maximum file size: 10 MB
- Ensure file is not password-protected
- Try a different browser or clear cache

**Accommodation letter not sent to instructor:**
- Check that you selected the correct courses
- Verify the instructor is listed in the system
- Contact Disability Services to resend
- Newly added courses may need manual letter generation
