Features

Built for real institutions

Production-grade tooling across every layer of the stack.

☰
Multiple Interfaces
CLI for automation, Tkinter GUI for desktop, Flask REST API for integrations, and a full browser-based Web Portal with SPA dashboard.
🔒
Shared Authentication
Unified auth across all 5 systems. bcrypt hashing, TOTP MFA, DB-backed sessions, WebAuthn, SSO (SAML/OIDC), and cross-system switching.
⚡
Unified REST API
All 5 systems served from one Flask server. JWT authentication, Swagger UI docs, versioned routes, rate limiting, and content negotiation.
🔴
Live Session Management
Real-time dashboard showing all active users. Admin force-logout kicks users within 5 seconds via session heartbeat polling.
◆
Domain-Driven Design
4-layer architecture with 492 domain modules. Clear separation between interface, service, infrastructure, and data layers.
🛡
Security First
RBAC with 355+ permissions, CSRF protection, Content Security Policy, SQL injection prevention, and comprehensive audit logging.
Quick Start

Up and running in minutes

terminal 
# Clone and install
git clone https://github.com/sean1352636/university_system.git
cd university_system
pip install -r requirements.txt

# Launch the interactive menu
python run.py

# Or go directly to what you need
python run.py --university --gui     # University GUI
python run.py --college --api        # REST API server
python run.py --school --cli        # Secondary School CLI
python run.py --primary --gui       # Primary School GUI

# Web portal at http://localhost:5000/web/login
# API docs at  http://localhost:5000/api/v1/docs
