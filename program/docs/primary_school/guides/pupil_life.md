# Primary School — Pupil Life Guide

> Covers 8 modules: Clubs, Meals, Transport, Trips, Library, Medical, Class Groups, Consent

Last Updated: March 2026

---

## Clubs

Manage extra-curricular and after-school clubs.

### Club Records

| Field | Description |
|---|---|
| Club Name | e.g., Football, Art, Coding, Choir |
| Day/Time | When the club runs |
| Location | Room or area |
| Staff Lead | Teacher or TA running the club |
| Year Groups | Which year groups can attend |
| Capacity | Maximum number of places |
| Cost | Free or charged (per term/session) |

### Key Workflows

- **Create a club** — Add club details, set capacity, and assign a staff lead.
- **Pupil registration** — Register pupils for clubs. The system prevents over-subscription.
- **Attendance tracking** — Mark attendance at each session. Track regularity.
- **Waiting lists** — When a club is full, additional sign-ups join a waiting list.
- **Reports** — View participation rates by year group and identify pupils not attending any clubs.

## Meals

Manage school meal choices, dietary requirements, and free school meal (FSM) entitlement.

### Meal Management

| Feature | Description |
|---|---|
| Daily Choices | Record meal selection (school dinner, packed lunch, home) |
| Menu Options | Set weekly menu choices (e.g., Option A, Option B, Jacket Potato) |
| Dietary Requirements | Allergies, vegetarian, halal, kosher, other |
| FSM Tracking | Record FSM eligibility and Ever6 status |
| Meal Counts | Daily meal count reports for the kitchen |

### Free School Meals

- Record FSM eligibility with start and end dates.
- Track **Ever6** status (eligible for FSM at any point in the last 6 years) for Pupil Premium funding.
- Generate FSM reports for census returns.

### Key Workflows

1. **Set up menus** — Enter weekly menu options for each day.
2. **Record choices** — Class teachers or admin record daily meal choices for each pupil.
3. **Dietary alerts** — Pupils with allergies or dietary needs are flagged in the meal system with prominent warnings.
4. **Reports** — Generate daily meal counts, FSM uptake reports, and dietary requirement summaries.

## Transport

Manage school transport arrangements.

### Transport Records

| Field | Description |
|---|---|
| Pupil | Linked pupil record |
| Transport Type | School bus, walking bus, parent drop-off, walks independently |
| Route | Bus route name/number |
| Pick-up Point | Designated pick-up location |
| Drop-off Arrangement | Who collects the pupil (named adults) |
| Notes | Any special arrangements |

### Key Features

- **Bus routes** — Define routes with stops and assigned pupils.
- **Walking buses** — Manage walking bus routes with supervising staff and registered pupils.
- **End-of-day arrangements** — Record how each pupil goes home. Changes from the norm require parent notification.
- **Ad-hoc changes** — Record temporary transport changes (e.g., "Pupil X going home with Mrs Y today").
- **Reports** — Generate transport lists by route or class for dismissal time.

## Trips

Plan and manage school trips and educational visits.

### Trip Planning

| Field | Description |
|---|---|
| Trip Name | Destination and purpose |
| Date(s) | Single day or residential dates |
| Year Groups | Which year groups are attending |
| Staff | Accompanying staff and adult:child ratios |
| Cost | Total and per-pupil cost |
| Risk Assessment | Attached risk assessment document |
| Consent Status | Tracking of returned consent forms |

### Workflow

1. **Create trip** — Enter trip details, dates, and costs.
2. **Risk assessment** — Upload or create the risk assessment. Requires approval before the trip proceeds.
3. **Consent forms** — Generate consent forms. Track which parents have returned signed forms.
4. **Payment tracking** — Record payments received. Flag outstanding payments.
5. **Pupil list** — Generate the final list of attending pupils with emergency contacts and medical information.
6. **Post-trip** — Record any incidents and close the trip.

### Consent and Payment Status

| Status | Meaning |
|---|---|
| Pending | Consent form sent, not yet returned |
| Consented | Parent has given consent |
| Declined | Parent has declined |
| Paid | Payment received |
| Part-paid | Partial payment received |
| FSM Funded | Cost covered for FSM-eligible pupils |

## Library

Manage the school library catalogue and book loans.

### Catalogue

- **Add books** — Enter title, author, ISBN, genre, book band/level, and location.
- **Categories** — Fiction, non-fiction, reference, picture books, early readers.
- **Book bands** — Link books to reading levels (colour bands) for guided reading.
- **Search** — Find books by title, author, genre, or level.

### Loans

| Field | Description |
|---|---|
| Pupil | Borrowing pupil |
| Book | Selected from catalogue |
| Date Borrowed | Loan date |
| Due Date | Return deadline (configurable, typically 1-2 weeks) |
| Date Returned | Actual return date |
| Status | On Loan, Returned, Overdue, Lost |

### Key Features

- **Issue a book** — Select pupil and book, confirm loan. Due date is set automatically.
- **Return a book** — Scan or select the book to mark as returned.
- **Overdue tracking** — View all overdue books. Generate overdue notices by class.
- **Reports** — Most borrowed books, borrowing frequency by pupil, stock check reports.

## Medical

Record medical information, manage medications, and log first aid incidents.

### Medical Records

| Field | Description |
|---|---|
| Pupil | Linked pupil record |
| Conditions | Asthma, epilepsy, diabetes, allergies, etc. |
| Medications | Name, dosage, frequency, storage location |
| Allergies | Food, medication, environmental, with severity |
| Care Plan | Detailed care plan document for complex needs |
| Emergency Contacts | Linked from pupil record |

### First Aid Log

- Record all first aid incidents: date, time, description, treatment given, staff member administering.
- Flag head injuries for mandatory parent notification.
- Track recurring injuries for safeguarding awareness.

### Medication Administration

- Log every instance of medication given: date, time, medication, dose, administered by.
- Parental consent for medication must be recorded before any medication is administered.
- Set reminders for regular medications.

### Key Workflows

- **Update medical info** — Record new conditions, allergies, or medications. Attach care plans.
- **Administer medication** — Log the dose given. Two-person verification is recommended.
- **First aid incident** — Log the incident. For head injuries, generate a parent notification automatically.
- **Reports** — First aid frequency reports, medication administration logs.

## Class Groups

Manage class and form group assignments.

### Class Structure

| Field | Description |
|---|---|
| Class Name | e.g., "Year 2 Oak", "Reception Sunshine" |
| Year Group | Reception, Year 1-6 |
| Class Teacher | Assigned teacher (STF ID) |
| Teaching Assistants | Assigned TAs |
| Pupils | List of pupils in the class |
| Capacity | Maximum class size (typically 30) |

### Key Features

- **Create classes** — Set up class groups for each year group with names and assigned staff.
- **Assign pupils** — Add pupils to classes. The system warns when capacity is exceeded.
- **Class lists** — Generate printable class lists with pupil details.
- **Year-end transition** — Move pupils to new classes for the next academic year.
- **Mixed-age classes** — Support for classes spanning two year groups (common in small schools).

## Consent

Manage parental consent for various activities and data usage.

### Consent Types

| Type | Description |
|---|---|
| Photography | Use of pupil photos on website, social media, displays |
| Trips | General trip consent (specific trips have individual consent) |
| Medical | Consent to administer first aid and specific medications |
| Data Sharing | Sharing pupil data with third parties |
| Online Services | Use of online learning platforms |
| Walking Home | Permission for a pupil to walk home independently |
| Sunscreen | Permission to apply sunscreen |

### Key Features

- **Request consent** — Send consent requests to parents for specific categories.
- **Record responses** — Log consent as granted or withheld, with date and parent name.
- **Bulk requests** — Send consent forms to entire year groups or the whole school.
- **Consent status** — View consent status for any pupil across all categories at a glance.
- **Expiry** — Set annual renewal dates for consent. The system flags expired consents.
- **Reports** — Identify pupils with missing or withheld consent by category.
