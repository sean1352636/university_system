## How to Use These Guides

### For Students

1. Start with the **Student Life & Support** section for services relevant to you
2. Use **Academics** guides for course, assignment, and grade help
3. Check **Campus & Facilities** for housing, health, and campus services
4. Refer to **Troubleshooting** sections within each guide if you encounter issues

### For Faculty

1. Review **Academics** guides for teaching tools (assignments, grading, virtual classroom)
2. Use **Administration** guides for system features (authentication, search, analytics)
3. Share relevant guides with students as needed

### For Staff & Administrators

1. Start with **Administration & Infrastructure** for system management
2. Use **Campus & Facilities** guides for operational management
3. Review **Commerce & Services** for commercial operations
4. Reference all sections for training new users
