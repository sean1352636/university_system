# Campus Events Hub - User Guide

## Overview

The Campus Events Hub is your central platform for discovering, creating, and managing events across campus. From academic conferences and cultural festivals to sports tournaments and charity drives, the Events Hub supports event registration, announcements, recurring event series, and attendance tracking for students, staff, clubs, and administrators.

## Getting Started

### Accessing the Events Hub

**For Students:**
1. Navigate to **Campus Life** → **Events Hub**
2. Login with university credentials
3. Browse upcoming events on the main calendar

**For Club/Organization Leaders:**
1. Navigate to **Campus Life** → **Events Hub**
2. Login with credentials
3. Access **Create Event** to organize new events

**For Staff/Admin:**
1. Navigate to **Administration** → **Campus Events**
2. Full management access to all events

### Events Hub Dashboard

**Dashboard Widgets:**
- **Upcoming Events**: Next 7 days of events
- **My Registrations**: Events you're registered for
- **Popular Events**: Trending by registrations
- **Event Calendar**: Monthly/weekly view
- **Announcements**: Latest event announcements

## Discovering Events

### Browsing Events

**Calendar View:**
1. Navigate to **Events** → **Calendar**
2. Switch between views:
   - **Monthly**: Overview of all events
   - **Weekly**: Detailed week view
   - **Daily**: Hour-by-hour schedule
   - **List**: Sorted list of upcoming events

### Filtering Events

**Filter Options:**
- **Category**:
  - Social
  - Academic
  - Sports
  - Cultural
  - Charity
  - Other
- **Organizer Type**:
  - Student
  - Club/Organization
  - Staff
  - Administration
- **Date Range**: Start and end dates
- **Location**: Building or venue
- **Free/Paid**: Filter by cost

### Event Details

**Event Information Includes:**
- Event title and description
- Category and tags
- Organizer name and type
- Date, start time, and end time
- Location (building, room, or virtual link)
- Capacity and spots remaining
- Registration requirements
- Contact information

## Event Registration

### Registering for an Event

**Registration Steps:**
1. Find the event in the calendar or list
2. Click on the event to view details
3. Click **Register**
4. Confirm your registration
5. Receive confirmation email with:
   - Event details and location
   - Calendar invite (.ics file)
   - Any preparation instructions
   - Check-in information

### Managing Registrations

**View My Registrations:**
1. Navigate to **Events** → **My Registrations**
2. See all events you're registered for
3. View registration status:
   - **Registered**: Confirmed spot
   - **Waitlisted**: Event is full, you are on the waitlist
   - **Checked In**: Attended the event
   - **Cancelled**: Registration cancelled

**Actions:**
- **Cancel Registration**: Free up your spot (notify organizer)
- **Add to Calendar**: Download calendar invite
- **Get Directions**: Map to event location
- **Contact Organizer**: Send message to event coordinator

### Capacity Management

**When an Event is Full:**
- You will be added to the waitlist automatically
- Receive notification if a spot opens
- Waitlist position is first-come, first-served
- You can cancel your waitlist position anytime

## Creating Events

### Who Can Create Events

| Role | Permissions |
|------|-------------|
| **Students** | Personal/informal events (with approval) |
| **Club Leaders** | Club-organized events |
| **Staff** | Department events |
| **Admin** | All event types, no approval required |

### Creating a New Event

**Steps:**
1. Navigate to **Events** → **Create Event**
2. Fill in event details:
   - **Title**: Clear, descriptive name
   - **Description**: Full details, agenda, what to bring
   - **Category**: Social, Academic, Sports, Cultural, Charity, Other
   - **Organizer Type**: Student, Club, Staff, Admin
   - **Date and Time**: Start date/time, end date/time
   - **Location**: Building, room number, or virtual meeting link
   - **Capacity**: Maximum attendees (leave blank for unlimited)
   - **Contact Email**: For inquiries
3. Set registration options:
   - Open registration or invite-only
   - Registration deadline
   - Waitlist enabled/disabled
4. Submit for approval (if required)
5. Event published to calendar once approved

### Editing Events

**Modify Your Event:**
1. Navigate to **Events** → **My Events**
2. Select the event to edit
3. Update any details
4. Save changes
5. Registered attendees are notified of changes

## Event Series & Recurring Events

### Creating Recurring Events

**Set Up a Series:**
1. When creating an event, enable **Recurring Event**
2. Set recurrence pattern:
   - **Daily**: Every day or every N days
   - **Weekly**: Specific days of the week
   - **Biweekly**: Every two weeks
   - **Monthly**: Specific day of the month
3. Set series end date or number of occurrences
4. Each occurrence appears as a separate event on the calendar

### Managing a Series

**Series Actions:**
- **Edit Single Occurrence**: Change one event in the series
- **Edit Entire Series**: Apply changes to all future events
- **Cancel Single Occurrence**: Cancel one date
- **Cancel Entire Series**: Cancel all remaining events

## Announcements

### Sending Event Announcements

**For Event Organizers:**
1. Navigate to your event → **Announcements**
2. Click **New Announcement**
3. Write announcement:
   - Subject line
   - Message body (location changes, reminders, updates)
4. Send to all registered attendees
5. Announcement delivered via email

### Types of Announcements

- **Reminders**: Sent before the event (e.g., "Event tomorrow!")
- **Updates**: Changes to schedule, location, or agenda
- **Follow-ups**: Post-event thank you, surveys, materials
- **Cancellations**: Event cancellation notices

## Check-In & Attendance

### Event Check-In

**Checking In Attendees:**
1. At the event, organizer navigates to **Events** → **Check-In**
2. Select the event
3. View registered attendees list
4. Mark attendees as checked in:
   - Search by name or student ID
   - Check the box to confirm attendance
   - Timestamp recorded automatically

### Attendance Reports

**After the Event:**
1. Navigate to **Events** → **My Events** → Select event
2. View attendance summary:
   - Total registered vs. attended
   - Check-in timestamps
   - No-show list
3. Export attendance data (CSV)

## Best Practices

1. **Create events early** - Post events at least 2 weeks in advance for maximum attendance
2. **Write clear descriptions** - Include what attendees should expect, bring, and wear
3. **Set realistic capacity** - Account for typical no-show rates (15-25%)
4. **Send reminders** - Use announcements to remind attendees 24-48 hours before
5. **Track attendance** - Check in attendees for accurate records and future planning
6. **Follow up** - Send thank-you announcements and feedback surveys after events
7. **Use categories** - Properly categorize events so students can find them easily

## Troubleshooting

### Common Issues

**Cannot register for an event:**
- Event may be at full capacity (check for waitlist option)
- Registration deadline may have passed
- Event may be invite-only
- Verify your login credentials

**Event not appearing on calendar:**
- Event may be pending approval
- Check your filter settings (category, date range)
- Refresh the page or clear cache
- Contact the event organizer to confirm status

**Cannot create an event:**
- Verify you have the correct role permissions
- Ensure all required fields are completed
- Check that the date/time does not conflict with existing bookings
- Contact administration if your role needs upgrading

**Check-in not working:**
- Ensure you are the event organizer or have admin access
- Verify the event date is today
- Search by full name or student ID
- Check internet connectivity
