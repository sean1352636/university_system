Last Updated: March 2026

## Behaviour

Log and track behaviour incidents across the school.

### Incident Recording

| Field | Description |
|---|---|
| Pupil | The pupil involved |
| Date/Time | When the incident occurred |
| Location | Classroom, playground, corridor, etc. |
| Type | Disruption, defiance, physical, verbal, bullying, other |
| Severity | Low, Medium, High, Critical |
| Description | Free-text account of the incident |
| Action Taken | Verbal warning, loss of playtime, phone call home, internal exclusion, etc. |
| Recorded By | Staff member logging the incident |

### Key Workflows

- **Log an incident** — Navigate to Behaviour tab, click Add Incident, fill in details, and save.
- **View pupil history** — Click a pupil name to see all behaviour incidents in chronological order.
- **Pattern tracking** — The system highlights pupils with recurring incidents. Filter by type, severity, location, or date range.
- **Parental notification** — Significant incidents can trigger a notification to parents.
- **Reports** — Generate behaviour summaries by class, year group, or whole school. Useful for governor reports and Ofsted evidence.

## Rewards

Recognise positive behaviour and achievement through a structured reward system.

### Reward Types

| Reward | Description |
|---|---|
| Stickers | Day-to-day recognition for effort and achievement |
| House Points | Points contributing to inter-house competitions |
| Certificates | Weekly/termly awards (Star of the Week, etc.) |
| Special Awards | Headteacher awards, golden time, prize box |

### How to Use

- **Award points** — Select a pupil or class, choose the reward type, and enter the number of points or select the certificate.
- **Leaderboards** — View house point totals and individual pupil totals.
- **Redemption** — Track rewards redeemed (e.g., golden time earned).
- **Assembly integration** — Generate lists of certificate recipients for celebration assemblies.
- **Reports** — View reward distribution by class, year group, or individual to ensure equity.

## Safeguarding

**Access restricted to Designated Safeguarding Lead (DSL) and admin users only.**

Safeguarding is the highest-priority module. It provides tools for logging concerns, managing referrals, and maintaining chronologies.

### Concern Logging

1. Navigate to Safeguarding tab (only visible to authorised users).
2. Click **Log Concern**.
3. Complete all fields:
   - Pupil name
   - Date and time of concern
   - Nature of concern (disclosure, observation, report from third party)
   - Category (neglect, physical, emotional, sexual, other)
   - Full description (record factually, use the child's own words where possible)
   - Immediate actions taken
4. Save — the concern is timestamped and attributed to the recording staff member.

### Chronology

- Each pupil with safeguarding records has a **chronology view** showing all concerns, actions, and referrals in date order.
- Chronologies can be exported as PDF for multi-agency meetings.

### Referrals

| Referral Type | Description |
|---|---|
| Internal | Escalation to DSL or headteacher |
| MASH/CSCS | Multi-Agency Safeguarding Hub or Children's Social Care |
| Police | For criminal concerns |
| Early Help | Early Help Assessment referral |
| Other Agency | CAMHS, health visitor, school nurse, etc. |

### Important Notes

- All safeguarding data is **encrypted** and access-logged.
- Only DSL and admin roles can view safeguarding records.
- Records are never deleted — they form part of the statutory safeguarding file.
- When a pupil transfers school, safeguarding files must be transferred securely to the receiving school.

## SEND (Special Educational Needs and Disabilities)

Manage the SEND register and provision for pupils with additional needs.

### SEND Register

| Field | Description |
|---|---|
| Pupil | Pupil name and ID |
| SEND Status | SEN Support, EHCP (Education, Health and Care Plan) |
| Primary Need | Cognition & Learning, Communication & Interaction, SEMH, Sensory/Physical |
| Date Identified | When the need was first recorded |
| Provisions | List of interventions and support in place |

### Key Workflows

- **Add to register** — Identify a pupil as SEN Support or EHCP. Record primary need category.
- **Provision mapping** — Document all interventions (1:1 support, small group, speech therapy, etc.) with start/end dates, frequency, and responsible staff.
- **EHCP tracking** — Record EHCP application dates, annual review dates, and outcomes.
- **Review scheduling** — Set review dates and generate reminders. Reviews typically termly for SEN Support and annually for EHCP.
- **External agency liaison** — Log involvement from external professionals (educational psychologist, speech and language therapist, occupational therapist, etc.).
- **Reports** — Generate SEND overview reports for governors, showing numbers on register, provision costs, and progress.

### Graduated Approach (Assess, Plan, Do, Review)

The system supports the graduated approach cycle:

1. **Assess** — Record baseline assessments and identified needs.
2. **Plan** — Document targets and planned interventions.
3. **Do** — Track delivery of interventions.
4. **Review** — Record outcomes and decide next steps.

## Pastoral

Record pastoral notes, wellbeing concerns, and maintain communication logs linked to pupils.

### Pastoral Notes

- Record observations about a pupil's wellbeing, home circumstances, friendships, or emotional state.
- Notes are visible to class teachers, pastoral staff, and senior leaders.
- Sensitive notes can be flagged for restricted access.

### Key Worker Assignments

- Assign a key worker (teacher or TA) to pupils who need additional pastoral support.
- Key workers are responsible for regular check-ins and maintaining the pastoral record.

### Wellbeing Concerns

| Concern Type | Examples |
|---|---|
| Emotional | Anxiety, low mood, bereavement, family changes |
| Social | Friendship difficulties, isolation, bullying (victim) |
| Home | Parental separation, housing issues, financial hardship |
| Health | Chronic illness impact, frequent absence |

- Log concerns with date, description, and actions taken.
- If a pastoral concern escalates to a safeguarding issue, it can be referred directly to the Safeguarding module.

### Parent Communication Logs

- Record conversations with parents/carers about pastoral matters.
- Log phone calls, meetings, emails, and letters with date, summary, and outcome.
- Linked to the pupil record for a complete communication history.
